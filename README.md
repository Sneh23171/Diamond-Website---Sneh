# 💎 Diamond Website

A fully responsive **Diamond Website** built with **HTML**, **CSS**, and **JavaScript**.  
Visitors can browse diamond products, make inquiries, and schedule appointments.

---

## 🌟 Features

- **Product Showcase** – Display of diamond products with images and details.
- **Inquiry Page** – Form for users to send product inquiries.
- **Appointment Page** – Users can book an appointment for diamond consultations.
- **Fully Responsive** – Works smoothly on desktop, tablet and mobile devices.
